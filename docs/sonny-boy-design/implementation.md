# 《漂流少年》AI NPC 实现方案

本方案以原作的世界规则、人物选择和播出顺序为设计底稿。首个验证场景选第 2 集的岛上蓝火，玩家跟随长良行动，目标是弄清蓝火如何发生，再决定怎样把发现告诉别人。它能在一个地点内检验规则、证据和人物动机。后续可以用第 6 集验证世界分岔与人物记忆。

## 世界和角色怎样配合

| 数据 | 需要记录的内容 | 第 2 集里的例子 |
| --- | --- | --- |
| **世界状态** | 地点、人物、物品归属、已经完成的动作和实际触发的规则。 | 谁拥有一件物资、谁取走了它、当时有无达成交换。 |
| **角色状态** | 当下目标、关系、已知事件、听来的说法、自己答应做的事。 | 看到蓝火的人知道火烧起来了。另一个人只听说瑞穗曾在现场。 |
| **场景进度** | 发生顺序、可见线索、触发条件，以及复盘原作时需要记录的关键事件。 | 在对照实验之前，起火原因仍是待验证的问题。 |

玩家提问或行动、消息传到某人耳边、或场景达到已设条件时，相关角色获得一次行动机会。参与的 NPC 依据自己的目标、关系和所见事实，给出回答或提出一个可执行动作，例如找人、交东西、公开证据、拒绝交涉。游戏根据角色是否在场、有没有该物品、能否使用能力来确定结果。结果写入事件记录，人物只有在亲眼看见或后来被告知时，才得到相应信息。线索记录保留消息来自谁、谁亲眼见过、哪些结果已经验证。玩家可以回头查一条流言经过哪些人，也可以追问为什么某个角色改变了判断。

### 一轮具体交互

1. **初始局面。** 岛上出现蓝火，有同学因为瑞穗负责供应物资就怀疑她。拉吉塔尼知道有一件换来的旧掌机没烧，但他还需要对照。瑞穗此时有找回猫和避免被围攻两件急事。
2. **玩家采取行动。** 玩家可以问目击者看见了什么、要求拉吉塔尼展示完好的掌机、征得拥有者同意再交换一件物品，或直接拿走同一件东西。NPC 可拒绝出借、去找证人，或者只转述自己听过的说法。
3. **场景执行结果。** 原作给了三种可观察的情形。用玩具换来的掌机保持完好，抢拾落下的钞票时蓝火迅速蔓延，瑞穗主动送给长良的草帽也被收下。验证场景先按这三个实例定义转手结果，保留初始所有人和具体转手记录。交换或赠予的归属变化由游戏确认。玩家与 NPC 能继续争论个别物品为什么没烧。
4. **证据改变关系。** 拉吉塔尼拿到对照结果之后，可以公开说明。某位角色接受了说明，也可以记得玩家曾跟风指责瑞穗。解释了蓝火和修复关系是两项不同的进展，各自保留后果。

原作复盘中，蓝火被查明、众人采用漂流币等关键事件有固定顺序。可以实验的空间来自另外记录的互动，例如先询问谁、哪条消息先传到瑞穗那里、哪些人愿意作证。等到后续开始改编时，可以逐场决定哪些结果开放给玩家改变。

场景用播出顺序定位，世界事件可以有自己的发生时间。第 8 集的山彦回忆属于过去，当前场的人从他的讲述获得信息。回忆中出现的人仍以当时的立场行动。

## 人物动机怎样转成可玩的动作

- **瑞穗**可能拒绝当众出借物资，也可能在私下交谈中愿意说自己看见了什么。同一请求在不同关系下可以得到不同回答。
- **拉吉塔尼**可以请求复现实验、把结果告诉亲眼见过火的人，或者先记录一个异常样本。证据收集和公开是两次可观察的行动。
- **明星**有维持队伍秩序的目标。事情不明时，他可能要求统一口径。这个动作可能短期减少冲突，也可能让当事人更不愿配合。
- **希**可能主动去确认瑞穗和猫的位置。她愿意下注在自己的线索上，因此不一定跟随队伍一起寻找嫌疑人。

角色资料里可以给不同阶段分别写目标与经历。一个人后来的选择可以启发作者设计，场中 NPC 只能按当时已经知道的事说话。给模型的资料应裁去未来事件和他人尚未公开的经历。世界规则、可执行动作、进度和记录由游戏程序管理。语言模型理解自由输入，生成一句对话，也可以提交一个带对象的行动请求。模型不可用时，场景可以按预写的角色反应继续，已经发生的动作仍由记录恢复。

## 怎样确认方案可行

| 验证 | 通过条件 |
| --- | --- |
| 重复蓝火实验 | 同一初始状态和动作组合得到相同的世界结果，NPC 用词可以变化。 |
| 改变访问顺序 | 先找目击者和先找拉吉塔尼，得到的线索路径不同，关键的物品归属和火焰事件可以追溯。 |
| 询问角色尚未知晓的事 | 角色按当时见闻回答，或明确说自己得去查。 |
| 提议越过规则 | 说自己拿走了物品只形成请求。实际归属变化出现在一次经过验证的行动里。 |
| 回放 | 用已经记录的动作和结果重建同一世界状态，避免重新生成对话导致过去发生的事变动。 |
| 验证分岔 | 在第 6 集，角色可以观察毕业典礼。漂流中的希伸手碰典礼里的朝风时，手会穿过去。不同版本的角色保有各自的记忆。 |

最小验证范围是一处岛营地、四个角色、三种转手方式和一次对照实验。世界观可以通过玩家得到的信息来体会，具体前端、模型、发布方式等到设计成立后再选。
