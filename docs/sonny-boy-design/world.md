# 《漂流少年》世界观拆解

这份文档以动画的 12 集播出顺序为依据。设计目标是找出哪些规则、人物选择和事件互相依赖，方便之后更换地点与社会背景。含全季剧透。

## 漂流怎样发生

暑假中，36 名初中生和学校一起进入虚空。一部分人发现自己拥有能力，另一些人在漂流前已经遇到异常。学生先尝试维持校内秩序，再到尽头之岛寻找回去的方法。第 6 集，他们借助胶片来到原校毕业典礼，能观察现场。希伸手触碰典礼里的朝风时，手从他身上穿了过去。校长借此提出「观测」与分岔副本的解释。第 12 集，长良和瑞穗抵达一个可以生活的日常世界。它与第 6 集所见的毕业典礼有重要差异，两个场景各自记录。

## 能推动故事的六条设定

| 设定 | 原作依据 | 设计上的区分 |
| --- | --- | --- |
| **地点有自己的规则** | 校舍与岛上物品受损后的表现不同。尽头之岛的蓝火能用物品如何易手来解释。第 5 集又发现，火灾后的岛依然存在。巴别塔则有自己的空间方向和通行条件。第 2、5、7 集。 | 以地点作为规则的作用范围，物品归属、损伤和通行由所在地点判定。 |
| **能力属于具体的人或物** | 希能看见别人看不见的光。朝风能操控重力。三只猫分担接单、复制和运送，瑞穗自己的能力另有作用。能力遗物也能参与探索。第 4、5、9、10 集。 | 能力需要使用者、条件和效果。复制出来的物品与原件可以分别追踪。 |
| **时间和生老状态可以分开** | 漂流者会经历很久，外表却可保持原样。山彦的漂流经历极长，长良等人跟希会合时也发现彼此对约定时间的感受相差两周。第 6、8 集。 | 区分地点经过的时间、人物经历的时间和身体状态。回忆与衰老可以产生不同结果。 |
| **规则有不同来源** | 第 1 集的学生立规、惩罚和明星的能力交织。第 2 集的蓝火则能用对照实验验证。第 6 集还有校长提供的解释。 | 区分可重复触发的现象、人物或组织设定的规则、角色提出的解释。每条记录保留来源。 |
| **同一人物的不同版本分别生活** | 毕业典礼呈现了未参与这段漂流的另一批学生。雪原上的庄和诚司由同一人分出，最后各自有不同经历和选择。第 6、9、12 集。 | 让共同身份与各版本的记忆、关系分开记录。终集的希和漂流中的希拥有各自的经历。 |
| **看见出口、前往出口和在那边生活是三件事** | 希能感知光，长良能带人跨越世界，但最初选不准目的地。能观察毕业典礼也并不等于能进入现场生活。第 4、6、11、12 集。 | 分开记录已发现的方向、已经打开的路径和穿越完成后的落点。 |

## 哪些部分需要保留悬念

- **漂流原因。** 亚希先怀疑有人使用能力，拉吉塔尼根据两座岛提出过「创造世界」的假说，校长则进一步提出「观测」解释。这几次说法都有具体情境。记录它们的提出人、提出时间和所依据的现象。
- **死亡。** 漂流中存在维持状态、恢复、消失和变成遗物等情形。第 10–11 集用希的死讯和发明死亡者的故事分别处理这件事。每种结果按发生的世界和对象记录。
- **人的动作。** 第 10 集，骨折能听见朝风的念头，实际行动还要等悬崖上的事发生。对角色的立场、意愿和实际动作分别记录，行动以场景发生的事为准。


## 世界之间怎样相连

| 地点或世界 | 在故事里怎样抵达或呈现 |
| --- | --- |
| 虚空校舍、尽头之岛 | 校舍被黑暗包围。希朝光跃出，长良跟着坠落，海与岛出现。岛后来成为多次探索的出发点。 |
| 平面国、火灾后的岛 | 探索者进入平面国并得到鼠标。另一次，长良等人在烧过的岛相会，由火灾痕迹确认那里与眼前的岛有差异。 |
| 胶片影院、毕业日 | 长良和拉吉塔尼找到保存影像的影院，借观测与合剪尝试返校。毕业日是一次可以观察的抵达。 |
| 巴别塔 | 长良在岛上的单杠翻身后进入。塔里的重力方向、搬运工序和能力限制构成了可探索的规则。 |
| 庆典之村 | 由山彦讲述过去。这里呈现他如何与小玉相遇、如何留在原地，应按过去的角色状态来理解。 |
| 雪原、战争所在的地方 | 两处各有冲突。前者通过庄与诚司展示回溯及两个版本可以分化，后者以朝风等人的行动试探死亡与能力遗物的关系。 |
| 次元交界、终集的日常世界 | 长良和瑞穗由发射行动到达交界，在朝风交回指南针后继续穿越，最终在另一处日常生活。 |

## 一条关键的事件链

| 集数 | 事件带来的改变 |
| --- | --- |
| 01–02 | 权威先靠立规与惩罚建立。蓝火危机出现之后，寻找责任人和找出触发条件产生了不同结果。 |
| 03–05 | 冻结事件和异世界探索扩大了队伍，也让能够跨越世界的长良逐渐成为被怀疑的对象。 |
| 06–07 | 毕业典礼上的返乡尝试告终，大家不再共享同一个目标。明星准备方舟，拉吉塔尼选择探索，长良在巴别塔经历了一次自己的判断。 |
| 08–10 | 山彦与小玉、庄与诚司、骨折与朝风依次呈现不同的人如何对待失去、重复和他人的去留。希最终坠落。 |
| 11–12 | 长良和瑞穗为希送别后决定出发。他们最终进入另一个可以生活的日常，保留了漂流记忆，也面对关系已经不同的现实。 |

后续做中国化时，可以先挑一个原有冲突，提取使它发生的地点规则、角色利益和社会权威，再在新背景里设计一组能产生同样复杂选择的事件。例如，蓝火冲突同时用到了物品的归属、同学之间的流言，以及谁有权宣布处罚。变更其中一项时，可以沿这三条关系核对谁首先受到影响。
