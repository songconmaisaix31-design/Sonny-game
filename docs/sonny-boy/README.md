# 《漂流少年》（Sonny Boy）全 12 集台词与音画拆解

《漂流少年》是夏目真悟执导、MADHOUSE 制作的 2021 年原创动画。这里按每集的实际叙事次序梳理主要场段，包含回忆、交叉叙事和结局剧透。想顺着某个人物重看，可以从[角色档案](characters.md)进入。

分集文档以中文转述关键对白，并分析对白怎样改变人物关系和推动情节。画面部分关注构图、空间、色彩、动作，声音与节奏部分关注对白疏密、叙事停顿、交叉切换和音乐进入的位置。

**时间点用于回看片段。** 时标来自公开的带时间码字幕，标的是场段内可定位的对白。播放版本和片头长度可能带来偏移。画面和声音依据官网剧照、字幕截帧、主创访谈和配乐资料整理。全季正片的逐镜时长无法依据这些资料确认。

## 全季的声音线索

第一集把主题歌留到海岛出现之后。第二集起，插曲通常集中在个别转折，例如第三集揭开黑幕、第五集夜钓、第十一集海边送别。第十二集分别给回归日常、穿越世界和最终车站相遇安排音乐。长时间由对白承担叙事之后，音乐的进入也在提示一段关系或行动发生变化。[导演谈声音留白](https://febri.jp/topics/sonnyboy1/) · [WEBアニメスタイル 逐集配乐分析](https://animestyle.jp/2022/09/06/22722/)
